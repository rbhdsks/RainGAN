# Attribution and licensing notice

RainGAN-Kathmandu builds on the public SyRaGAN implementation associated with:

> Jaewoong Choi, Daeha Kim, Sanghyuk Lee, and Byung Cheol Song, “Synthesized rain images for deraining algorithms,” *Neurocomputing*, 2022. DOI: 10.1016/j.neucom.2022.04.034.

The model and training utilities also contain code derived from StarGAN v2 by NAVER Corp. The relevant source files retain the original attribution header and the Creative Commons Attribution-NonCommercial 4.0 notice.

No repository-wide license was present in the original RainGAN repository. This refactor therefore does **not** assign a new license to code whose ownership or downstream licensing has not been established. Users must review the upstream SyRaGAN/StarGAN v2 terms and the terms of each dataset before redistribution or commercial use.
